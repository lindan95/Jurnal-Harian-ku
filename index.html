Pengaturan Database Google Apps Script & Drive

Hubungkan aplikasi web ini dengan Google Sheets dan Google Drive Anda.

*URL ini didapatkan setelah Anda men-deploy skrip di Google Apps Script sebagai Web App (Execute as: Me, Access: Anyone).

2. Cara Deploy Kode Backend Google Apps Script (Code.gs):

  1. Buka Google Spreadsheet baru di Drive Anda (Beri nama: Database Jurnal Guru SMAN 05 Bombana).
  2. Klik menu Ekstensi → Apps Script.
  3. Hapus semua kode yang ada di editor Apps Script, lalu salin seluruh kode Code.gs di bawah ini.
  4. Klik tombol Deploy (Terapkan) → Deployment Baru.
  5. Pilih Jenis: Web App. Isikan deskripsi, set Execute as: Me, dan Who has access: Anyone (Siapa saja).
  6. Klik Deploy, lalu berikan izin akses (*Authorize Access*).
  7. Salin Web App URL yang diberikan dan tempelkan pada kolom nomor 1 di atas.
